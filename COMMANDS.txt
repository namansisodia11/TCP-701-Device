0502  Delete user (by card, PIN or ID)                    [TESTED 2026-10-02, type 01]
      We send : 1 byte type + 4 bytes key. 01 = by card number, 02 = by PIN, 03 = by user ID
                e.g. 01 000000B3 = delete card 000000B3
      Answer  : OK. User count stays the same (5): type 01 removes only the CARD from the user
                entry; the entry (user ID 00B3, PIN FFFFFFB3) stays.
      Notes   : offline QR for 000000B3 refused right after (3 beeps, 0214 50FF...B3). Removing a
                member's card stops their offline QR codes immediately.
                Type 03 = delete the whole user by USER ID, written FIRST in the 4 bytes:
                  03 000000B3 -> status 1 (failed);  03 00B30000 -> OK (entry gone: deleting its PIN then
                  failed, and re-adding the same card + PIN succeeded).
                The user count (0202) never goes down: 5 after deletes, 6 after re-adding B3.
                It counts entries ever added, not current users. Whether deleted slots are reused is unknown.
                Right after a power-up 0202 can read too low (5 / 106 at 18:53), then back to 6 / 121 next day.
